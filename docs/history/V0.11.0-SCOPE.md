# Hidden Conviction v0.11.0 Scope

This release implements the complete reliability and engineering improvement pass requested after the live v0.10.0 review.

## P0 reliability

- [x] Replace guessed SEC same-day daily-index URLs with SEC directory metadata discovery.
- [x] Make recovery business-day/publication aware by selecting only actually published indexes.
- [x] Walk multi-day gaps forward from the oldest unreconciled published index.
- [x] Support quarter-boundary recovery.
- [x] Persist a last fully reconciled SEC filing date distinct from latest filing seen.
- [x] Record reconciliation receipts and enforce `discovered = processed + pending + failed` before advancing the watermark.
- [x] Persist Cron start, finish, status, duration, summary, and exception receipts.
- [x] Change health from unconditional OK to `ok`, `degraded`, or `error` stage semantics.
- [x] Add exponential retry timing, retry counts, next retry timestamps, and dead-letter timestamps.
- [x] Add admin replay for failed filing work and failed score recomputation.
